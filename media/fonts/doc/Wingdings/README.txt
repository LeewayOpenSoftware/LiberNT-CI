Wine Wingdings (Dmitry Timoshkov) (ReactOS/LiberNT family name kept for compatibility)

wingding.ttf is the Wine project's Wingdings font, a free design that provides
the glyph repertoire of the Windows "Wingdings" family at the same code points.
It is shipped as Wine built it (name table: family "Wingdings", unique ID
"FontForge 2.0 : Wingdings", vendor "Wine", version 001.000).
