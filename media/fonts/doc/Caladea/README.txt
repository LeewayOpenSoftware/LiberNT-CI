Caladea 1.002 is the interim substitute for "Cambria" and "Constantia"
(FontSubstitutes), until an original Leeway font replaces it. It is not
Microsoft's font and ships unmodified.

Origin:  ChromeOS crosextrafonts-20130214.tar.gz
         https://commondatastorage.googleapis.com/chromeos-localmirror/distfiles/crosextrafonts-20130214.tar.gz
         sha256 c48d1c2fd613c9c06c959c34da7b8388059e2408d2bb19845dc3ed35f76e4d09
         (by Huerta Tipografica; the later google/fonts Caladea is a redesign with
         different widths and is not metric compatible)
Licence: Apache License 2.0 (LICENSE.txt), as stated in the fonts' name table.
Metrics: advance widths match Cambria for all of ASCII. Greek and Cyrillic are not covered.
Note:    Caladea-BoldItalic.ttf names its subfamily "Italic"; weight and style
         bits are bold italic, which is what GDI matches on.
