Wine Symbol (Jon Parshall for CodeWeavers) (ReactOS/LiberNT family name kept for compatibility)

symbol.ttf is the Wine project's Symbol font, a free design that provides the
glyph repertoire of the Windows "Symbol" family at the same code points. It is
shipped as Wine built it (name table: family "Symbol", unique ID "WineSymbol:Version 1.1",
vendor "Wine", version "1.1 February 3, 2009, initial release").
