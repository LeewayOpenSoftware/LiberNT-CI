# sdk/lib/tl4

Vendored copy of Theme Loader 4 (private Leeway repository `ThemeLoader4`). The commit is in `TL4_COMMIT`, and the
SHA-256 of every vendored file is in `MANIFEST.sha256`. Files are never edited here; an update replaces the
directory and both files in one commit.

- `trust`: the pure decisions of the uxtheme trust gate (THEME-TRUST-POLICY T-DEF-1..5).
- `loader/pe`: the bounded PE/resource reader.
